# Geometry-Aware Control Barrier Functions for Collision Avoidance via Bernstein Polynomial Approximations

Project page for the ICRA 2026 paper by Siwon Jo, Yanze Zhang, Yupeng Yang, and Wenhao Luo.

- Project page: https://bp-sdf-cbf.github.io/
- Paper: https://arxiv.org/abs/2605.30696

The videos in `static/videos/` are rendered from the simulations of the paper (single robot among
composite obstacles in C-space, two unicycle robots, four heterogeneous robots). The second teaser row
uses the same shapes with BP-SDFs refitted by a boundary-weighted regression (not in the paper).
